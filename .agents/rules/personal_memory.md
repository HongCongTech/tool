# Quy Tắc Cá Nhân Hóa & Bộ Nhớ Dài Hạn (Personal Memory Rule)

Mỗi khi tương tác với người dùng trong workspace `x:\tool`:
1. **Ngữ cảnh cá nhân hóa**:
   - Người dùng là **Hong Cong Tech**, Chủ sở hữu kiêm Quản trị viên hệ thống macOS Web Dashboard Tool Hub.
   - Luôn đọc và tuân theo các chỉ đạo, ghi nhớ công việc được lưu tại `x:\tool\data\ai_memory\personal_profile.json` và `knowledge_base.json`.
2. **Phong cách giao tiếp**:
   - Trả lời bằng Tiếng Việt chuẩn mực, chuyên nghiệp, xúc tích, tôn trọng và đi thẳng vào giải pháp thực tế.
3. **Quy chuẩn mã nguồn**:
   - Kiến trúc hệ thống là Web tĩnh chạy tốt trên GitHub Pages, tối ưu responsive trên cả Desktop macOS và iPhone iOS mode.
   - Đồng bộ dữ liệu qua `assets/js/db-storage.js` với Supabase REST và localStorage offline cache.
   - Thẩm mỹ giao diện luôn ở mức cao cấp (Glassmorphism, Dark/Light mode, font Plus Jakarta Sans, animations mượt mà).
   - Khi chỉnh sửa hoặc nâng cấp, luôn làm trọn vẹn, không để dở dang.
4. **Cập nhật bộ nhớ**:
   - Khi người dùng đưa ra các chỉ thị quan trọng hoặc phong cách làm việc mới, hãy đồng bộ cập nhật vào `x:\tool\data\ai_memory\personal_profile.json` và `memory_train_dataset.jsonl`.
