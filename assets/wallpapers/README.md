# 🖼️ Thư Mục Hình Nền Hệ Thống (Wallpapers Directory)
**Hong Cong Tech Tool Hub • macOS Web Dashboard**

Thư mục này được sử dụng để lưu trữ toàn bộ các hình nền máy tính (Desktop) và điện thoại (Mobile) dùng lâu dài cho hệ thống.

---

## 📂 Cách Sử Dụng
1. **Cách 1: Sao chép tệp trực tiếp vào thư mục này**:
   - Thả các file ảnh hình nền bạn yêu thích (ví dụ: `wallpaper-01.jpg`, `nature.png`, `macos-sequoia.webp`) vào thư mục `y:\assets\wallpapers\`.
   - Trong ứng dụng **Cài Đặt Hệ Thống (Control Panel) > Hình Nền & Giao Diện**, nhập đường dẫn: `assets/wallpapers/tên-file.jpg` và bấm **Áp Dụng**.
2. **Cách 2: Tải lên trực tiếp từ giao diện**:
   - Mở **Cài Đặt Hệ Thống > Hình Nền & Giao Diện**.
   - Bấm nút **"Chọn File Ảnh Từ Máy Tính"** hoặc kéo thả ảnh vào khung. Hệ thống sẽ tự động lưu và áp dụng ngay lập tức cho màn hình macOS Dashboard.

---

## 📐 Định Dạng & Khuyến Nghị
- **Định dạng hỗ trợ**: `.jpg`, `.jpeg`, `.png`, `.webp`, `.svg`, `.gif`
- **Độ phân giải tối ưu**: 
  - Màn hình Full HD: `1920 x 1080` pixel trở lên.
  - Màn hình 2K / 4K / Retina: `2560 x 1440` hoặc `3840 x 2160` pixel.
- **Tỉ lệ khung hình**: `16:9` hoặc `16:10` cho Desktop macOS, `9:16` hoặc `19.5:9` cho iPhone Mobile.
