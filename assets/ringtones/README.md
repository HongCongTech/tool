# 🔔 Thư Mục Nhạc Chuông & Âm Báo (Ringtones & Audio Directory)
**Hong Cong Tech Tool Hub • macOS Web Dashboard**

Thư mục này được sử dụng để lưu trữ toàn bộ các file nhạc chuông, âm báo thức, tiếng thông báo nhắc việc và hiệu ứng âm thanh sử dụng lâu dài cho hệ thống.

---

## 📂 Cách Sử Dụng
1. **Cách 1: Sao chép tệp âm thanh trực tiếp vào thư mục này**:
   - Thả các file âm thanh yêu thích (ví dụ: `chuong-bao-thuc.mp3`, `ding.wav`, `apple-opening.m4a`) vào thư mục `y:\assets\ringtones\`.
   - Trong ứng dụng **Cài Đặt Hệ Thống > Âm Thanh & Thông Báo**, bạn có thể nghe thử và chọn làm chuông mặc định.
2. **Cách 2: Tải lên trực tiếp từ giao diện Control Panel**:
   - Mở **Cài Đặt Hệ Thống > Âm Thanh & Thông Báo**.
   - Bấm nút **"Tải File Nhạc Chuông (.MP3 / .WAV)"**. Hệ thống sẽ tự động thêm vào thư viện nhạc chuông cá nhân, cho phép bạn nghe thử trước khi đặt làm âm báo chính thức.

---

## 🎵 Định Dạng & Khuyến Nghị
- **Định dạng hỗ trợ**: `.mp3`, `.wav`, `.m4a`, `.ogg`, `.aac`
- **Dung lượng khuyến nghị**: `< 5MB` cho một file nhạc chuông (giúp tải nhanh và không tốn bộ nhớ đệm trình duyệt).
- **Thời lượng tối ưu**:
  - Âm báo thông báo / Click: `0.2s - 2s`.
  - Nhạc chuông nhắc việc / Báo thức: `5s - 30s`.
